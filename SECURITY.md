# Security

Report a vulnerability to security@buildhound.sh, not in a public issue. Say what you found, how to reproduce it and what it reaches. We reply within two working days, and we credit reporters who want it once a fix has shipped.

What is in this repository runs on your own machine or in your editor: the CLI, the MCP server, the rules and the cost model. The control plane, the dashboard and the machine agent are not here; a report about them goes to the same address. How jobs are isolated and what a machine can reach is described at https://buildhound.sh/docs/security.
